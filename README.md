# TravelGoGo ✈️ - 智能直式旅遊行程規劃神器 (PWA & Web)

> **專為手機直式體驗打造的現代化旅遊規劃工具**。免伺服器、零登入負擔，資料全本地加密快取，支援透過 **GitHub Pages** 一鍵發布，並能像原生 App 一樣安裝至手機主畫面（PWA）隨身離線使用！

---

## ✨ 核心特色與強大功能

### 1. 📱 專為手機直式打造的 10 分鐘精準時間軸
- **全日 24 小時直式時間軸**：以 **10 分鐘為標準網格** 清楚呈現行程分佈與留白空檔。
- **⏱️ 時段快速跳轉列**：頂部提供 `[⏱️ 現在]`、`[08:00]`、`[12:00]`、`[15:00]`、`[18:00]`、`[21:00]` 快捷晶片，一鍵平滑滾動到目標時段。
- **🔴 動態現在時間指針**：當瀏覽當天行程時，時間軸顯示即時呼吸脈衝紅線，旅遊現場進度一目了然。
- **多天跨欄檢視**：支援 1 天、3 天、5 天或 7 天多欄對比並排，輕鬆掌握整趟旅程走勢。
- **雙檢視切換**：可隨時在「直式時間軸視圖」與「簡潔卡片摘要列表」間自由切換。

---

### 2. 🗺️ Google Maps 智慧解析與批次匯入
- **支援地圖清單網址解析**：貼上 Google Maps 清單短網址（如包含數十個儲存景點的分享清單）即可在瀏覽器端自動解析出地點名稱、經緯度、地址與備註。
- **多行文字與分享文字智慧提取**：可直接貼上包含地點、括號備註、地址與連結的文字，系統自動去重並格式化。
- **即時預覽與勾選**：解析後可預先編輯名稱、查看 Google 地圖外鏈，支援一鍵全選或個別勾選。

---

### 3. 🔖 口袋名單 (Wishlist) 預備景點庫
- **預備地點管理**：先將想去但尚未排定時間的美食、購物、打卡景點加入口袋清單。
- **重複子項智慧忽略 (Deduplication)**：
  - 批次匯入時，已在口袋名單中的地點會自動標註 `[已在口袋]` 並預設不勾選。
  - 匯入或排程時自動比對名稱與地圖連結，**重複地點自動忽略**並即時顯示跳過數量提示。
- **即時關鍵字搜尋過濾**：景點再多也能瞬間用名稱或備註快速檢索。
- **一鍵快速排程**：直接從口袋名單挑選景點帶入行程，或一鍵批次排入指定天數。

---

### 4. 🗓️ 旅遊區間月曆選取與天數快速預設
- **直覺月曆選擇器**：選擇「開始日期」與「結束日期」，系統自動建立天數標籤與對齊對應星期幾（如 `Day 1 10/10(六)`）。
- **快速天數預設鍵**：提供 `[3天]`、`[4天]`、`[5天]`、`[7天]`、`[10天]` 常用旅遊長度，點擊即可自動推算結束日期。
- **天數標籤自動置中**：點選或滑動切換天數時，天數分頁自動平滑置中顯示。

---

### 5. 🗂️ 靈活卡片拖曳與時段衝突提示
- **卡片自由拖曳**：按住手柄即可直接上下拖動調整時間（自動吸附 10 分鐘刻度），放開時彈出時段確認。
- **時段重疊智慧排版**：同一時段若有多個行程（例如自由活動分頭逛街或彈性備案），自動雙欄並排不互相遮蓋。
- **⚠️ 重疊標籤提醒**：時段衝突卡片自動標上醒目的重疊警示，規劃更踏實。
- **時長快捷增加**：編輯行程時提供 `[+30分]`、`[+1小時]`、`[+1.5小時]`、`[+2小時]` 快捷鍵，自動換算結束時間。

---

### 6. 🚇 交通轉乘提示與自由空檔分析
- **交通方式設定**：支援地鐵／火車、步行、公車、計程車、自駕、飛機等多種交通標記與備忘。
- **☕ 自由空檔提示 (Transit Gap)**：行程間若有 30 分鐘以上留白空檔，自動在時間軸上提示「☕ 自由空檔 XX 分鐘」，掌握悠閒步調。

---

### 7. 🗺️ 互動式路線地圖與導航
- **內建 Leaflet 互動地圖**：自動將當日所有景點標記在地圖上，並依時間順序繪製路線軌跡連線。
- **一鍵啟動 Google 導航**：點擊卡片地圖按鈕或路線圖底部的「在 Google 地圖開啟完整導航」，立即開啟 Google Maps App。

---

### 8. 💰 預算費用與記帳管理
- 支援為每個景點與活動記錄開銷（可切換日圓 JPY、台幣 TWD、韓元 KRW、美金 USD、歐元 EUR 等）。
- 自動計算當日花費小計與整趟旅遊總支出，換算財務狀況一清二楚。

---

### 9. 🖨️ 紙本手冊列印與 PDF 匯出優化 (Print Friendly)
- 內建專屬 `@media print` 高對比紙本排版。
- 按下瀏覽器列印（`Ctrl + P` 或手機列印）即自動隱藏工具列與懸浮按鈕，轉化為排版工整的離線紙本行程或 PDF 電子手冊。

---

### 10. 💾 本地安全儲存與一鍵分享
- **LocalStorage 自動快取**：每次修改均即時自動存檔，重整或斷網不丟失。
- **下載 / 匯入 JSON**：隨時備份行程檔案給朋友。
- **文字代碼分享**：一鍵將完整行程壓縮為代碼字串，直接貼在 LINE 或通訊軟體傳送，旅伴點擊即可匯入。

## 🚀 部署至 GitHub Pages（超簡單免費發布）

1. 將本專案的所有檔案推送到您的 GitHub Repository：
   ```bash
   git add .
   git commit -m "feat: deploy TravelGoGo"
   git push origin main
   ```
2. 進入該 GitHub 儲存庫頁面，點選 **Settings** > **Pages**。
3. 在 **Branch** 選取 `main` 分支並選擇 `/ (root)`，按下 **Save**。
4. 約 1~2 分鐘後即可透過 GitHub 提供的網址（例如 `https://<username>.github.io/<repo>/`）直接在手機或電腦上開啟使用！

## 📲 手機上當成原生 App 使用 (PWA)

本專案支援 PWA（Progressive Web App）標準，可無痕安裝至手機桌面：
- **iPhone / iPad (iOS Safari)**：
  - 點擊底部「分享按鈕（帶箭頭的方形）」➔ 選擇「加入主畫面 (Add to Home Screen)」。
- **Android (Chrome / Edge)**：
  - 點擊右上角「更多選單（三個點）」➔ 選擇「安裝應用程式」或「加到主畫面」。

安裝後即可享受全螢幕無網址列的原生 App 沉浸體驗，離線狀態亦可照常查看行程！
